Observed: the agent set `fileParallelism: false` in the release project of `vitest.workspace.ts` (steps 322, 348) and reran the release tier. Scenario files still ran concurrently and the intermittent page-load hangs continued. The agent then ran `npx vitest --help` (step 412), which lists `--fileParallelism` / `--no-file-parallelism`, and passed `--no-file-parallelism` on the command line (steps 430, 508). The workspace file's own comment (step 420) says the project-level setting is silently ignored.

Concluded: under vitest 1.6.1 the workspace project setting does not take effect for this setup, so the flag must go on the command line (`package.json` `test:release`). This was not verified against the vitest source. The test failures remained after the flag change, so the flag alone did not make the release tier pass.
