- Only the three emitter sub-modes remain core tools. A bare createTestEngine knows those and nothing else.
- Every ToolContext fake needs chosenFlagType; every AimPick literal needs eyePoint.
- Typing on a sign must not use commandInFlight: the menu page holds the text, each key submits the whole message, the world applies them in order. A guard would drop keys and could drop a delete right after a key.
- Flag, length and angle runtimes are built from the journal in syncToolObjectRuntimesFromJournal, so a created record appears after the tick, not at the click.
- A world reset removes flags, lengths and angles by engine.submit; the reset frame's step(0) applies them.
- In this working copy sed -i really does strip CRLF; git normalises it on commit, so it only shows as a warning.
