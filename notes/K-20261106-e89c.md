Carry held still 1 s after the crossing vanished, then applyGeometryCommitComputedObjectPolicy: removedProtractorAngleIds [angle], with 3 s still left. Same scene with the carry ended first: the angle is kept, because settleGeodesics writes segments and the next pass forgets the marker. Free geodesics are deleted by a commit anyway, so this reaches only connected ones.
