Observed:
- At step 58, `npm run bench -- moduleStep --check` reported `check: FAILED (flow step time)` and the tool output said to settle it with `npm run bench:ab -- <start commit>`.
- At step 60, after `sleep 55` and a rerun, the same check reported `check: ok` (flow 17.91 us/step, idle allocation 559.0 bytes/step).

Concluded (single occurrence, not verified as flakiness):
- The flow timing gate may be sensitive to machine load right after other heavy runs. A rerun after a pause passed without any code change.
- Before treating a timing failure as a regression, rerun the check after a pause, or use `bench:ab` against the start commit as the tool suggests.
