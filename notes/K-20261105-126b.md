## Observed
- Cleanup removed the node_modules junctions in two sibling worktrees first (noneuclid-carryend, noneuclid-carryrec), then ran `git worktree remove --force`.
- The removal of noneuclid-carryend failed with `error: failed to delete '.../noneuclid-carryend': Permission denied`. The worktree was still present afterward.
- A later process listing showed a `node` process running `...\noneuclid-carryend\node_modules\.bin\..\vite\bin\vite.js`, so a Vite process started from that worktree was still alive.

## Concluded (hypothesis)
A live Vite process started from a worktree probably holds files in it open, which blocks deletion on Windows. Stopping that process before `git worktree remove` is the likely fix. This was not tested in the session.
