Observed: after `sed -i` on `_issues/62_segment_based_portal_traversal_and_swept_motion.md` (step 57 and step 61), the tool output warned that the command modified a file previously read and asked for a Read before editing. The later Edit calls on that file needed a fresh Read.

Concluded: Bash in-place edits clear the Edit tool's prior-read record for that path. Either do the sed edit and then Read, or use Edit only and avoid Bash writes to the same file.
