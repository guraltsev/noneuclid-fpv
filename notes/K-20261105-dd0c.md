Observed: the first bench:ab of 7a46f09 against the working tree showed head slower than base (flow 21.09 vs 18.53 us/step; flow+dependents 37.61 vs 33.11). A later run of the same kind at ce6fe57 showed head faster (flow 17.17 vs 19.88; flow+dependents 30.5 vs 35.08). Both runs were in the background on the same machine. A check run also reported a timing failure on a flow step before a rerun passed.

Concluded: on this machine the bench gate's timing differences are of the same order as the noise between runs, so it should not be read from one run. Repeat it and compare the rounds.
