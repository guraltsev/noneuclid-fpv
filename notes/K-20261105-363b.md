**Observed:** A Bash tool call containing a long pipeline with nested quotes and `sed`/`grep` expressions exited with code 2 (`unexpected EOF while looking for matching`). The same kind of work then succeeded when the commands were written to a `.sh` file in the session scratchpad and run as `bash "<path>.sh"`.

**Concluded:** On this environment, complex quoted shell commands are more reliable when written to a script file and run with bash, not passed inline. The scratchpad path is the safe place for these files.
