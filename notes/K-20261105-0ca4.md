Observed:
- The first run of the new ghost contract test failed 4 of 24 cases (steps 81-82). The archetype map included unused geodesic segment ribbon archetypes with count 0.
- A second run also failed because shared geodesic sources create archetypes for kinds not present in the scene (steps 90-91).
- The agent kept only archetypes that have instances and excluded the segment kind, which is exempt from the ghost rule (steps 92-95). All 24 tests then passed.

Concluded:
- Archetype maps from geodesic render sources are not a reliable list of what is drawn. Test helpers should filter by instance count, and segment ribbons are a separate exempt kind.
