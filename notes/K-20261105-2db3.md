## Observed (2026-11-05)

- `.agents/knowledge` and `.agents/agents-md` in this repository are junctions to `C:/Users/guraltsev/Documents/templates/agents/.agents/`. That repository holds the code history and the test suite (`.agents/knowledge/_tests/`), run with its own `.venv`. Commits to the tool belong there, not here.
- `Path(__file__).resolve()` followed the junction, so the default root became `templates/agents`. Hooks are registered without `--root` and fail open, so they did nothing and said nothing from about 02:50Z; the last line in `session-job.log` was from 02:45Z. `know_report` showed the error: no knowledge worktree in `templates/agents`.

## Concluded

- `knowledge.py` now passes `os.path.abspath(__file__)` parents to `main(default_root=...)`, because `abspath` does not follow links and `Path.absolute` keeps `..` from the launchers. `install.py` does the same.
- After a silent stop, check `.agents/.state/knowledge/session-job.log` for the last job, then run a launcher by hand, since the hooks hide their errors.
- Running the tests inside a Claude session needs `CLAUDE_CODE_SESSION_ID` cleared; the root `conftest.py` now does that.
