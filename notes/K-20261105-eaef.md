## Observed (2026-11-04)

- `.agents/agents-md` is a junction to `C:/Users/guraltsev/Documents/templates/agents/.agents/agents-md`.
- `installed_root()` (agents-md.py line 574) returns `Path(__file__).resolve().parents[2]`, so the default root is `templates/agents`.
- `agents-md.py check` with no root printed both files up to date, exit 0. `check --root .` printed AGENTS.md out of date, exit 1. `build --root . --dry-run` showed the expected fragment changes (17-working-files.md and the 70-knowledge.md edit).
- `templates/agents/AGENTS.md` is gitignored there and had a modification time of 2026-11-04 22:11, while this repo's AGENTS.md was last written at 06:04. That timing suggests a default-root build rewrote the templates copy, but this was not proven.
- `install.py` line 23 also uses `Path(__file__).resolve()`; its effect was not examined. No test in `.agents/agents-md/_tests` mentions installed_root, junctions or symlinks.

## Concluded

- Workaround: `_scripts/agents-md build --root .` from the repository root.
- Likely fix, same as the knowledge tool (K-20261105-2db3): use `os.path.abspath(__file__)` parents, not resolve. Not applied as of this note. The code lives in the templates/agents repository.
