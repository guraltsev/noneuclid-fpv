## Observed (2026-11-04)

- `.agents/agents-md` is a junction to `C:/Users/guraltsev/Documents/templates/agents/.agents/agents-md`, so code changes and commits belong in that repository.
- With `Path(__file__).resolve()`, `agents-md.py check` printed both files up to date (exit 0) while `check --root .` printed AGENTS.md out of date. A new junction test failed before the fix with project/AGENTS.md missing, and both scripts exited 0.
- `templates/agents/AGENTS.md` is gitignored and had a modification time of 22:11 on 2026-11-04, which suggests a default-root build rewrote it; this was not proven.

## Concluded

- `installed_root()` and `install.py` now use `Path(os.path.abspath(__file__))` with `# noqa: PTH100`, because ruff's suggested `Path.resolve()` is the bug.
- The junction test lives in its own module `_tests/test_agents_md_link.py` marked `process`, because conftest.py refuses subprocesses in `unit` modules.
