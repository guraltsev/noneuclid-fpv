## Observed (2026-11-05, this machine)

- `~/.claude/projects/<slug>/` held 29 main transcripts and 136 subagent transcripts; the slug is the project path with every non-alphanumeric character written as `-`.
- Subagent files sit at `<session>/subagents/agent-<id>.jsonl` beside a `.meta.json`, in the main format, with `sessionId` set to the parent. They can start with a `fork-context-ref` record.
- Subagents held most of the output: `d70f4628` had 91,106 main output tokens and 530,326 in subagents; `b63b43d7` had 22,118 and 150,291.
- `~/.codex/sessions` held 1,743 rollouts from all projects, about 32 from this one. The first line is `session_meta` with `cwd`, about 19 KB, so reading all first lines on every prompt is wasteful; the prompt hook only opens files changed in the last 7 days.
- A grader call cost about $0.01 (two logged calls, claude-haiku-5-5).

## Concluded

- The cursor, not a marker or a remembered size, is the record of what was processed: a session is unread while a cursor is behind its file. A size recorded when a job starts hides failed jobs.
- Byte ranges repeat across a session's transcripts, so idempotency keys must name the source transcript.
- `reports.pairs` keeps the latest non-unknown grade per session and note, so a later grade replaces an earlier one without double counting.
- A grader asked about a note read in an earlier range needs its title and summary: the digest of a later range does not show the note.
