**Observed:** A bench script timed the build for four torus-skew deformation parameter pairs (a, b). The build took 96-127 ms each, with 1793 kept paths in every case. Structured cloning of the result took about 9.3-9.6 ms. Compiling the base spec took 0.024 ms. The skew value a did not noticeably change the cost.

**Concluded:** Each deformation rebuild is dominated by the full compile and portal-path search, not by the base spec compile. Any design that rebuilds every frame or every small input change would be limited to roughly 10 rebuilds per second at best, so the step size per rebuild matters for responsiveness. This was measured on one machine and one world (torus-room), so generalise with care.
