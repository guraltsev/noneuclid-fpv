Observed (step 46-48): a know_write call with a field named "evidence" failed with "field(s) not accepted in a write request: evidence". The accepted fields were listed in the error: body, confidence, created_by, evidence_level, expires_at, id, related, source_branch, source_commit, source_files, source_session, status, summary, supersedes, tags, title, trust, type, valid_when.

Observed (step 44, from the event log): earlier writes failed with "missing required field(s): type, confidence" and with "type must be one of discovery, procedure, decision, constraint, antipattern, environment, open_question; got 'finding'".

Observed (step 50): the same call succeeded after renaming the field to evidence_level.

Concluded: the write schema is strict. Use evidence_level, and always set type and confidence to values from the enum.
