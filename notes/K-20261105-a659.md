- tests/project/testHygiene.test.ts is in the unit tier and passes when run alone.
- It imports scripts/tests/hygiene.mjs through a variable path. The digest says this is to avoid TypeScript type-checking.
- scripts/tests/hygiene.mjs defines gitTrackedFiles() at line 24 and calls it at line 529 (allTracked = gitTrackedFiles()).
- The H2 check, as described in the digest, matches only the test file's own literal import text, so the variable-path import does not match it.

Concluded (not directly observed at runtime):
- Running the unit test spawns a real `git` process through execSync inside the unit tier. This breaks the rule that unit tests touch no process or network boundary.
- H2 cannot detect this because it inspects only literal import text.
