Full design in issue 95, implementation in job 67. Tested only in a throwaway Python prototype on a synthetic tile (real KTX2 not decoded; GLSL and GPU cost not tested); the statements about validation and words are from reading the code.

- Seamless, rigid and carried cannot all hold as one global map; a seamless rigid single image is impossible unless the lattice is a sublattice of the tile lattice.
- Rigid patches: anchors at o + i u/nU + j v/nV, patch uv = G (p - A) with G constant from the base state. Anchor UVs are integers, so no per-anchor offset exists. At rest and at every Dehn twist of the square the floor equals the rest floor exactly.
- Failed variant: with kernel exponent 16 an absolute weight cut-off leaves pixels with no sample (max kernel can be 8e-8). Use max(k - 0.02 kmax, 0).
- Exponent 6 leaves wide double-image bands; 16 is narrow.
- 3x3 neighbour search in a reduced basis suffices for tau in [0,2]x[1/2,2] with nU = nV; it is not guaranteed for strongly non-square anchor lattices.
- Reduced footprint: side count, pairing and side lengths are all preserved, so validateTopologyPreservingSnapshot already accepts it; points keep p and wrap by a lattice vector. rebuildConnectedGeodesicBetweenEmitters uses the stored word, which is what a re-marking breaks; carriedPortalWord is the existing way to pass a new word.
- The (a, b) parameter box is not hyperbolically convex: the geodesic between (0,30) and (30,30) rises above Im tau = 2.
