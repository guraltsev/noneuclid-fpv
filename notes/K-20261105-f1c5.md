## Observed
- After new functions were added and old ones moved (job 21), `npm test` failed in a docs check: `FAIL document references (2)`. `_docs/MATHEMATICAL_MODEL.md` cited `src/render/three/visiblePortalPaths.ts#buildPortalApertureCorners` and `#clipConvexPolygonByConvexPolygon`, and the checker reported no top-level declaration with those names.
- The agent rewrote the affected section 8 paragraph and `_docs/ARCHITECTURE.md` text to describe the new funnel design, then ran `npm run docs:generate` and `npm run docs:check`, which passed.

## Concluded
- `docs:check` resolves `path#symbol` links against top-level declarations, so renaming or removing a function breaks the doc reference even when the code is correct. Update or remove those references in the same change.
