Evidence: 2026-11-05 I ran `git worktree remove --force` on .worktrees/oracle-base with the junction in place. Afterwards the directory remained holding only the junction, and `npm ls --all` reported no missing or invalid packages. The coordinator job notes warn about this risk. Safe order: `cmd //c "rmdir .worktrees\\<name>\\node_modules"`, then `git worktree remove`.

Also: `npm run bench:ab` refuses a dirty tree. To compare uncommitted work, alternate `npm run bench -- moduleStep` between a temporary worktree at HEAD and the working tree; one full round pair takes about 3 to 4 minutes, so three rounds exceed the 10 minute foreground limit.
