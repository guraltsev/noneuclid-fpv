SessionEnd: all 6 sessions with event files had a live claude.exe by start time. Session d70f4628 ran /exit at 13:39Z and got "/exit isn't available in this environment". Only 2 of 6 sessions have session_usage events; those jobs line up with PreCompact (compacted marker mtime) or an agent run. The only grader call ever made had trigger=agent, so hook-started grading has not been seen live. Whether SessionEnd fires and its detached job survives when a panel really closes is NOT verified.

Orphan sweep: it works in a scratch clone (hook spawned the job, usage logged, cursor advanced in 6 s). Live, a replay of real prompts says it should have fired at 2026-11-04T23:00Z for 39f6e1d2 (marker 565 min old), but no usage event exists and the agent job at 23:05Z started from byte 0. Cause unknown; spawn_detached sends the job's stdout and stderr to DEVNULL, so a failure there leaves no output. The sweep also sees only the single marker, so a session whose marker is overwritten by another within 30 min is never swept.

Attribution: active-session.json is last-prompt-wins. d70f4628 made three know_write calls at 11:42:19-30Z (the K-20261104-43d0 write and two validation errors); all three are logged under c43035db, whose only prompt finished by 11:38Z. A read logged this way would also be missing from the real session's grading plan.

Relevance: minimum fused score is 1/(RRF_K+AUTO_MIN_RANK) = 1/65, so any note in the top 5 of one ranking passes; there is no absolute similarity floor. In the clone, 'banana bread recipe with walnuts' and 'how do I file my taxes in Portugal' each returned 2 notes (K-20261104-60fc, K-20261104-3772).
