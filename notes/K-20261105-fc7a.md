Audit and fixes on 2026-11-04 (session b4de2396).

SessionEnd: all 6 sessions with event files had a live claude.exe, and d70f4628 got "/exit isn't available in this environment". Only 2 of 6 had usage records, from PreCompact or an agent run. Whether SessionEnd fires and its detached job survives when a panel really closes is still NOT verified. Fix: one marker per session in .agents/.state/knowledge/sessions/, and each prompt starts the job of the longest idle other session. Idle is judged by transcript mtime, not the marker, because one turn can run 9 hours after its only prompt. swept_size stops repeats.

Unexplained: replaying real prompts says the old sweep should have fired at 2026-11-04T23:00Z for 39f6e1d2, yet no job ran. d70f4628 was ruled out as the target: the reader yields a chunk for its tail, which would have moved the cursor, and it never moved. The old code sent job output to DEVNULL, so the cause is lost. Job output now goes to session-job.log and failures log an operational_error, which know_report counts; before this no report showed those events.

Attribution: the old single active-session.json was last-prompt-wins. d70f4628's three know_write calls at 11:42Z were logged under c43035db. Probed with claude -p: CLAUDE_CODE_SESSION_ID reaches hooks and MCP servers with the child's own id and matches the hook payload, also after --resume. CLAUDE_PID is NOT set for MCP servers (it was only inherited). Behaviour after /clear inside a live session is not verified: an MCP server started before it may keep the old id. MCP servers load code at start, so a running session keeps the old attribution until restarted.

Relevance: the cosine floor of 0.6 was already sound (targets 0.67 to 0.84, unrelated at most 0.544 over 26 notes). The leak was KEYWORD_MIN_RATIO, which is relative to the best keyword hit, so a weak best hit passes itself. Fix: with an embedder, a keyword hit must also be semantically related or contain every search term. Exact identifiers embed poorly (worldEngine 0.569), so a higher cosine floor would have lost them.

Testing traps: notes quoting a test query match it literally; a query starting with -- is parsed as an option by argparse; inline Python heredocs through the Bash tool get mangled, so write scripts with the Write tool.
