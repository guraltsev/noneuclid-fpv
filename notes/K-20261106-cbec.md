From running batch 61-66, 2026-11-05 and 06.

- `node -e` with quoted strings through the Volta shim silently did nothing twice (once it put a red commit af9f046 on the branch, once it left literal placeholders in a Report). Use the Edit tool or a script file, and read the result before committing. Cause not investigated.
- `sed -i` in Git Bash strips CRLF even when the pattern does not match; a no-op `sed -i` can mark a file modified. Git normalises it, so it does not show in commits.
- `npm run bench -- moduleStep --check` exited 3 on timing on most final commits of the batch, with counters unchanged, while the base itself read 20 us/step against 16 to 17 earlier that day. Only `bench:ab` in one session means anything. Single `bench:ab` runs also vary: the same comparison base gave exit 1 once and exit 0 later. syncthing had the most accumulated CPU time when checked once; a possible cause, not confirmed.
- Run the bench with a pause after tsc or docs:generate: a bench started right after them read about 45 us/step for flow+dependents.
- `npm run docs:writers` is a lower bound: it does not count writes through owners, and misses element access, structural types and destructured declarations (see also K-20261106-0164).
- `moduleStep.bench.ts` never calls `applyControls` and its idle scene has no modules, so neither its counters nor its idle bytes say anything about the fast channel (see also K-20261105-9570).
- `moduleTicks.ts` gave bodies and simulate ticks `changesFrom = frameStartSeq`, not a per-tick cursor, at review of job 61: a simulate tick would miss writes from earlier no-tick frames and see earlier ticks of its own frame again. Reported by a reviewer from reading the code, not run; latent until a simulate tick reads it. Check current code.
- Client code that checks a world fact each frame and submits a command resubmits in no-tick frames; `ToolContext.commandInFlight()` is the guard for tools.
- A lower median over an odd window flips every frame on a 50/50 two-period cadence; an even window with a true median holds, but only for period 2.
- `Array.prototype.sort` allocated about 1 KB per call on 10 numbers in node 24, measured by a reviewer; avoid it in per-frame code.
- A new worktree has no `dist/`, so `npm run smoke` exits 2 until a build runs.
- A message tagged `[handback-send-enforce]` appeared seven times in this run, seemingly when a coordinator ended a turn with nothing in the background. The launching session said no one had asked for a hand-back. Keeping a background wait running seemed to avoid it; that is an impression, not a test.
