Observed: the controller test (tests/render/scenePaletteControllerScale.test.ts) passed its assertions, but vitest reported 2 unhandled errors ('real timers are not allowed (delay 1000 ms)' from tests/support/unitSetup.ts) raised via @pmndrs/uikit InstancedPanelGroup.requestUpdate during dispose. Switching to vi.useFakeTimers() cleared the errors, and the test file then passed.

Concluded: the unit tier forbids real timers; uikit dispose schedules one, so controller tests that dispose the panel must use fake timers. Evidence is limited to one test file run in this session.
