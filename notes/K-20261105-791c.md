## Observed (2026-11-05)

- Running the external tests in the templates/agents repository gave 2 failures: `_tests/grading/test_real_grader.py::test_the_real_grader_answers_a_small_digest_with_output_that_passes_validation` and `_tests/workflows/test_claude_code_real_session.py::test_a_real_claude_code_run_gets_a_brief_reads_a_note_and_logs_its_usage`.
- Both stopped before doing anything. The environment had neither `ANTHROPIC_API_KEY` nor `CLAUDE_CODE_OAUTH_TOKEN` set.

## Concluded

- These failures reflect missing credentials, not a code defect, so a green run of the default suite does not show the real grader works.
- Before treating the external tests as evidence, set one of the credentials and rerun them, or check the real grader separately (for example, by sweeping a copy of a real session).
