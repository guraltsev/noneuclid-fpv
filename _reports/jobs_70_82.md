## Findings worth saving as project knowledge

- Layer rules: `ui` cannot import `interaction`; `runtime` cannot import `ui`; `modules`/`authoring` cannot import
  `ui` or `glue`; `world-objects` cannot import `engine`. Shared small types live in `glue` or `world-objects`.
- `npm run smoke` does not build; run `npm run build` first or it checks a stale `dist`. `npm test` is the `unit` and
  `process` projects; the `release` tier needs a built app and a browser.
- Anything used by `syncDesktopPalette` must be declared before `createThreeApp`'s first sync (a TDZ error that
  typecheck does not catch).
- Test hygiene: H5 forbids job numbers in test comments; H6 needs a leading doc comment of at least 30 characters and
  test names of at most 90 characters. Palette controller tests need `tests/support/fakeCanvas2d.ts` and
  `vi.useFakeTimers()`.
- The uikit palette font has no glyph for U+00B7 (middle dot) and `fakeCanvas2d` has no `createRadialGradient`.
- Headless CDP recipe: `scripts/lib/cdpClient.mjs` plus `scripts/smoke/staticServer.mjs`; stub
  `document.pointerLockElement`; `noneuclidDebug.setPlayerPose(...)`; `window.noneuclid.api.view.screenshot()` when
  `Page.captureScreenshot` fails. Yaw convention: forward is (-sin yaw, cos yaw).
- The working tree mixes CRLF and LF; scripted edits must handle `\r\n`. On this machine run vitest from PowerShell,
  not Git Bash.
